# Colorado Hunting Atlas (web version)

2026 Colorado big game atlas by Andrew Haag, built in ArcGIS Pro and exported to a Leaflet web map.

Open the map: see the GitHub Pages link in the repository's About section.

Data: Colorado Parks and Wildlife (GMUs, big game brochure, species activity mapping), BLM Surface Management Agency, Colorado State Land Board.
Basemaps: USGS The National Map (public domain).

Not an official CPW product. Check the current CPW Big Game Brochure and regulations before hunting.
